# vedio-download

使用当前仓库或用户明确指定的 `VIDEO_PARSER_ROOT` 项目 CLI。名称按用户要求保留为 **vedio-download**，不要改成 video-download。

## 首次收到链接：先问，再做

**这是用户要求的固定交互顺序。首次收到一个新的链接，先展示功能菜单，并询问用户需要什么；在用户回答前，不解析、不下载、不发送画面给模型。即使首次消息写了“下载”，也先展示菜单、确认是否按下载执行。**

可以先运行本 skill 的 `scripts/video_download.py capabilities --json` 获取当前功能，这是离线命令。若运行不了，使用下面的已知菜单并说明环境需要检查，不要为了列菜单启动服务、安装依赖或访问平台。

用中文列出：

1. **下载视频**：保存 MP4；B站下载独立音轨并合并，检查成品有画面和声音。
2. **仅解析信息**：标题、平台、封面地址、视频直链；不下载文件。
3. **下载封面**：保存封面图片。
4. **提取画面**：从本地视频提取指定数量的画面；只有链接时需先下载。默认 8 帧，不宣称是场景边界检测。
5. **分析画面内容**：抽样画面交给 Qwen3-VL，概述场景、人物、动作或主题；不是语音转录。
6. **自定义问题**：按用户的问题分析画面，例如“总结拍摄手法”。同样需要模型 API。
7. **组合操作**：例如下载＋封面，下载＋8帧；多步骤共用一次下载结果。
8. **音频转文字**：下载后用 `transcribe` 转写本地音视频，生成 TXT/SRT；复用本机 Whisper，不上传音频，不是平台字幕。

已有本地文件还可列出视频、调用系统播放器打开。平台字幕请使用工作台 B站字幕面板，CLI 不单独提取音频；不要把 AI 画面分析包装成完整字幕、逐字稿或对口播的可靠总结。平台列表来自代码，不代表所有平台今天都可用。

最后只问一句自然语言问题，例如：**“你希望做哪项？可以直接说‘下载视频’、‘只保存封面’或‘下载并提取 12 帧’。”** 有链接时不要再问用户重复提供它；没有链接时请他提供链接和所需操作。

展示菜单后结束本轮，等待回答。用户回答后就是对所选操作的授权，不要在每一轮重复菜单或要求再次确认。用户给新链接时重新进入首次询问。

## 根据选择执行

运行入口：`scripts/video_download.py`（绝对路径由本 skill 所在目录确定）。该脚本自动使用项目 `.venv`，转发参数并保留退出码，不依赖当前终端目录。

- 初次执行时可运行 `doctor --json`，判断所选功能需要的环境是否就绪。没有 API 密钥不妨碍普通下载、封面或画面提取。
- 命令与参数见 [references/cli.md](references/cli.md)。将链接或分享文本作为一个参数传递，使用参数数组或正确的 PowerShell 引号，不拼接进未经转义的 shell 命令。
- 默认按视频保存到项目 `outputs/<平台>/<标题>__<视频ID>__Pxxx`；同一视频的封面、视频、抽帧和分析复用一个项目，B站不同分P分开。经过校验的既有成品可复用，冲突不覆盖。用户显式指定 `--output` 或 `--output-dir` 时保持原路径语义；不要移动或删除原文件。
- 对“链接＋提取画面/分析”及组合任务，先下载一次，使用返回的 `path` 完成后续步骤。已有合适文件时可直接用本地路径，不反复下载。
- 转录使用本地文件路径；未知录音语言使用 `--language auto`，用户指定中文/英文时使用 zh/en。通过 `doctor` 检查 `transcription_ready`，缺失时只提示检查 `WHISPER_ROOT`，不安装模型；结果按输出文件核验，空正文说明未识别有效语音，失败的部分输出不宣称完成。
- 分析会把抽样画面发送给 `QWEN_API_BASE_URL` 指定的模型服务，可能产生费用。在选择菜单/执行前明确提示这点；用户明确选择分析后再调用。未配置 `QWEN_API_KEY` 时说明缺少配置，**不要询问用户在聊天里粘贴密钥**，也不要转用其他收费服务。
- 只下载用户有权访问和使用的内容；遇到平台登录、风控、付费或地区限制，停止并说明情况。不要自动提取浏览器 Cookie、切换登录账号、绕过权限或连续刷请求。

## 验证和交付

使用 `--json`，检查进程退出码及 `ok`。非零退出或 `ok: false` 是失败，不能凭“文件存在”宣称成功。

- 下载结果包含 `path`、`size_bytes`、`media`。检查媒体轨道、时长及分辨率；清楚说明本次实际取得的画质，不承诺 1080p 或“最高平台画质”。
- 封面返回文件路径；画面提取返回 `frames` 列表，核对数量；AI 分析返回 `analysis` 和可选报告路径，注明基于抽样画面。
- 用中文简洁交付，给出文件的绝对路径/可点击本地链接、大小及相关信息。不要在回复中暴露 API 密钥、Cookie 或整串签名媒体 URL，除非用户明确要求解析直链。
- 网络失败可使用解析器返回的备用 CDN（CLI 已内置）；一轮仍失败时说明原因和下一步，不无休止重试，也不自动重写项目或安装软件。
- `play` 成功只表示系统已收到打开请求，不声称亲眼确认播放。

## 路径与边界

在仓库内运行时，启动器根据自身位置定位项目根目录，不依赖盘符。复制安装到个人 Skill 目录后，应由用户设置 `VIDEO_PARSER_ROOT` 指向项目；先验证其中存在 `cli.py`，不要猜路径或克隆替代项目。可版本控制源位于 `skills/vedio-download`，个人安装通常位于 `~/.codex/skills/vedio-download`。
