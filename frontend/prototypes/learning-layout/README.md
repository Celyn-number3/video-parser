## 打开

- 双击 `index.html` 即可离线使用；样式和脚本全部内嵌，没有网络依赖。
- 需要本地网页时：`python -m http.server 15003 --bind 127.0.0.1`，然后访问 `http://127.0.0.1:15003/`。这不是正式应用的端口，也不会启动后台业务。

## 和现有视频工作台相比改了什么

1. **「AI 分析」里视频和笔记并排**：左边视频，右边分析记录。点笔记里的时间点只跳转视频，不再切到「视频预览」；往下读笔记时，视频固定在视野里。已有分析记录时，「新建分析」默认收起。
2. **分集列表**：检查器里列出这门课的全部分集，显示「已学完 n / 35」、进度条和「学到 Pn」。点一行切换到那一讲；没归档的分集沿用现有的「先归档视频」。
3. **「已学完」标记**：视频下方和列表里各有一个勾选框，两处同步；以前学过的分集可以直接在列表里补标。当前这一讲标记后出现「继续学 Pn」。

其余保持现状：侧栏四个页面、三个标签、分析表单、追问、复制和导出、下载归档。

## 窄屏

- 1360 像素以下：紧凑检查器移到上方，把宽度让给「视频 | 笔记」；分集列表收起为「展开分集列表」，从列表选一讲后自动收起。
- 860 像素以下：视频固定在顶部，笔记在下方滚动；窗口高度不到 560 像素时不再固定。
- 760 像素以下：侧栏改为抽屉菜单。

## 建议审阅顺序（约 3 分钟）

1. 默认在 P3：点笔记里的 13:12，视频跳转，笔记不动；继续往下滚动，视频仍在原处。
2. 勾选视频下方的「已学完」，看列表、计数和「学到 P4」变化，再点「继续学 P4」。
3. P4 还没有笔记：选「学习笔记」，点「开始分析」，笔记出现在视频旁边。
4. 在列表里勾选 P5、P6，模拟补标以前学过的分集。
5. 点 P7（未归档），点「先归档视频」。
6. 把窗口缩窄：检查器移到上方，列表收起，视频固定在顶部。

## 边界

- 课程、分集、笔记和进度都是示例；笔记是原型示例文本，不是对资料库视频的实际分析。
- 不联网、不读写文件、不调用模型、不登录、不写入 `library/`。CSP 设置了 `connect-src 'none'`、`media-src 'none'`、`form-action 'none'`。
- 状态只保存在本页内存中，刷新即重置。
- 沿用正式前端的 Mono 黑白设计令牌和侧栏 / 顶栏结构，支持浅色与深色主题；保留可见焦点、键盘切换标签、弹窗 Escape 与焦点恢复，并遵循「减弱动态效果」系统设置。

## 源文件与重建

- `index.html`：可直接使用的便携交付文件（由构建生成）。
