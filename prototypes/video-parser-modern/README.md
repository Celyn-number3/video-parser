## 打开

- 双击 `index.html`，即可离线使用；样式、脚本和示例封面全部内嵌，无 CDN 或网络依赖。
- 需要独立本地网页时：`python -m http.server 15002 --bind 127.0.0.1`，然后访问 `http://127.0.0.1:15002/`。这不是正式应用的15001端口，也不会启动后台业务。
- Arena 会话中已提供独立实时预览，使用8080端口。

## 建议审阅顺序（约5分钟）

1. **视频工作台**：看紧凑链接区、大预览和右侧归档面板；切换视频、封面、B站字幕和AI分析标签。
2. 点击“下载并归档”，立即填入“山行手记”示例并点击解析。海岸短片的模拟任务会继续，完成后不会覆盖当前项目；在任务中心点击该任务“打开项目”才能返回原项目。
3. **B站字幕**：选范围、获取字幕，体验示例扫码登录。山行手记提供8个示例分集，可试 `1-3,8`；海岸短片只有1集。扫码弹窗可切换加载、已扫码、过期和失败。
4. **音频转文字**：点“使用示例文件”，提交两个独立模拟任务；切换页面不会丢失文件选择或语言。可从任务中心取消单项、重试和查看结果；TXT/SRT只展示另存副本预览。
5. **任务中心 / 设置**：看任务筛选、详情、失败重试、缓存保护说明和会话偏好；运行任务期间不能确认模拟清理。
6. 将窗口缩小至手机宽度，体验选择后自动关闭的导航菜单、上下排布和弹窗。页头“演示状态”用于快速查看示例状态，不是实际服务状态。

## 边界与安全

- 所有项目、进度、状态、二维码、路径与结果均为示例。任意有效链接只触发内置素材演示，不实际解析平台页面。
- 示例封面为AI生成；播放按钮只演示静态图片上的控制条，不播放真实音视频。
- 文件选择或拖放仅获取文件名、大小、类型等元数据；不读取文件内容、不上传。
- 不下载、不写入归档、不打开系统文件夹、不登录账号、不保存凭据、不推理、不计费、不删除缓存。
- CSP明确设置 `connect-src 'none'`、`media-src 'none'`、`form-action 'none'`。没有业务接口请求或云端依赖。
- 状态只保存在本页内存：导航保留，刷新或关闭重置；不会冒充真实任务恢复。
- 同一项目的不同画质是独立归档版本，不改变项目身份。任务持有所属项目快照，旧项目完成不会抢占当前项目。
- 深绿/薄荷配色、均衡密度，完整路径与诊断按需展开；保留可见焦点和减弱动效设置。没有新增主题功能。

- `validation.json` / `验证说明.md`：本次原型验证结果，不是正式业务或原生设备验收。

运行测试需额外安装 Playwright 与 Chromium：

```bash
python -m pip install playwright
python -m playwright install chromium
# Linux首次运行可能还需要 python -m playwright install-deps chromium
# 另开终端在本目录启动静态服务后：
python test_prototype.py
# 其他预览地址通过 PROTOTYPE_URL 环境变量指定。
```
