### 上下文问题的机制

旧流程中，“项目已有归档视频”和“当前选中画质有可用本地媒体”不是同一条件。重新解析分集可能选中尚未归档的平台默认画质，使媒体上下文为空，而项目侧仍显示已归档。现在已归档分集优先本地恢复，并始终按当前项目/逻辑视频资源绑定材料、章节、对话与学习数据。

## 2. 新命名功能如何使用（部署后）

1. 在**学习视图或 AI 学习材料管理顶部**点击“字幕层级命名”。
2. 检查系列范围，勾选已有本地视频和 SRT/VTT 字幕的分集。B站以同一 BV 号为系列；其他平台当前仅处理当前项目。
3. 选择已有 API 或本地代理模型，并明确同意本次字幕处理及可能的联网费用，然后生成建议。
4. 编辑序号和语义标题，例如 `1.1 变量基础.mp4`、`2.2.1 类型转换.mp4`。本次最多选择 150 讲。
5. 点击“验证并预览最终文件名”。任何编辑或取消分集选择都会使当前确认失效，必须重新验证。
6. 检查源文件 → 目标文件清单，再勾选真实文件改名确认，点击执行。执行前会暂停当前播放器，并要求其他后台任务完成。
7. 完成后刷新当前媒体、标题和学习项目列表；可使用“恢复原命名”。关闭面板不取消后台任务，可从任务中心或最近记录继续。

**不会拆分视频，不会自动下载缺失视频或生成缺失字幕，也不会因为打开面板就调用模型。** 原有“修改课程显示标题”仍是独立的元数据功能。

## 3. 数据与事务保障

- 文件仅在原目录内更名，保留扩展名；多个归档画质使用独立后缀。项目 ID、逻辑资源标识和画质标识保持不变。
- 统一解析逻辑资源与物理文件别名，涵盖播放、下载、转写来源、AI 输入、CLI 分析来源、导出与 ZIP 清单。
- 同步界面分集标题；字幕、AI 材料、对话、个人笔记和学习进度继续绑定原来的稳定标识。
- 检查 Windows 禁用/隐藏字符、层级序号、重复序号、已有目标、大小写冲突、路径长度与来源变化。预览令牌绑定当前清单，执行前重新核验视频完整哈希。
- 使用无覆盖硬链接与持久事务记录，先保留副本，再更新引用，最后移除旧名字；不使用覆盖式视频替换。文件系统不支持硬链接时安全拒绝，不静默复制或移动视频。
- Web 任务互斥及项目锁保护协作操作。检测到外部文件替换时保留可用副本与恢复记录，不覆盖新出现的文件。执行期间仍请停止外部编辑/搬动，不宣称能阻止不配合的外部程序。
- 提交阶段不插入取消检查，完成后可撤销；在提交前取消则保持原文件。恢复仅合并命名所拥有的字段，保留后来新增的学习数据与课程显示标题修改。
- 模型仅产生建议，不能直接决定文件操作。请求包括课程/分集标题与全系列可用字幕的有界选段，不包含视频、聊天或个人笔记。选段不是逐字全文；超出安全上下文预算时拒绝，不隐式拆成多次付费请求。
- API 仅允许本机同源请求；模型处理同意与真实文件改名确认都要求字面布尔值 `true`，不能用 `1` 或字符串替代。
