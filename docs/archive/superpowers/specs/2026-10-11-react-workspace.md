# React 视频工作台迁移规格

## 已确认目标与约束
沿交接文档完成 React + Vite + TypeScript 迁移；保留 Python 平台解析器、CLI、skill、旧 API 和 Gradio 回退。用户明确授权中途自主决策、只看最终产品，因此不重复请求设计/计划审批，直接在当前工作树内执行，不创建分支、不提交、不推送。

## 界面
深色石墨灰与薄荷绿。上方分享链接输入与真实解析状态，下方桌面左侧 16:9 工作区、右侧信息和下载，900px 以下单列。视频预览、封面、AI 分析为键盘可操作的独立标签。所有按钮及带边框区域保留柔和阴影。不恢复口号、装饰编号、LOCAL WORKSPACE、假进度、模型装饰标签、固定 MP4 标签或宣传页脚。

## 架构与数据边界
新增 workspace.py FastAPI router，复用 cli.parse_link/download_video/save_cover/probe 和 qwen3vl.analyze_video。api.py 仅注册新路由、提供构建后的前端和 assets；旧 API 校验不变。使用同源 HTTP 与随机不可猜测资源 ID；不接受浏览器传入媒体直链、文件路径或密钥。每次解析独立状态，资源仅来自本次生成的受控 cache/react-workspace/<id> 目录。Web 路由限制本机请求、Host、Origin 和 JSON 写请求，启动器只监听回环地址，不把 Vigenère 当登录认证。

## 操作
解析返回标题、平台、原链接与本地封面；封面不可用时显示真实警告但保留视频解析。加载预览和下载共享一次服务器下载及 B站合并，重复操作复用成品并阻止并发重复处理。失败可重试，不发布部分文件。返回可播放、支持 Range 的媒体 URL 和带友好文件名的下载 URL。
AI 要求已下载视频、后端配置密钥、明确同意发送抽样画面和可能费用；帧数 1–16，提示词有长度上限。只分析画面，不称为字幕/口播/音频总结。不发送无效或无同意的请求。切换输入/清空中止客户端等待，迟到响应不可污染新状态。

## 范围与验收
不新增登录、历史、云部署、大型 UI/状态库。保留已有未提交内容及用户缓存/输出，不改 CLI/skill/Gradio。新增脚本先构建前端，再启动本地新版；旧进程不无条件重启。验证 Python 全套、TypeScript/生产构建、本地真实媒体经真实 API 的封面/预览/下载/合并/分析（模拟模型）、失败重试、隔离与文件安全、1440/768/390/320px 响应式、阴影/键盘/减少动画。真实平台与收费模型若未调用必须明确标注。
