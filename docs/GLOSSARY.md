# Video Parser 视频资料管理

用于获取、整理和使用视频、字幕及转写成果的本地工作台。以下术语区分资料的组织、处理过程和保存方式。

## Language

**视频项目**：
围绕一个视频或分集组织的资料单元，可包含不同画质版本及其关联资料；不同画质并不等于不同项目。
_Avoid_: 下载任务（用作项目名称）、素材任务

**处理任务**：
对素材执行一次视频获取、字幕获取、转写或画面分析的处理过程。任务的运行状态与资料是否已保存是不同概念。
_Avoid_: 项目（用作处理过程名称）

**归档**：
把视频及相关资料保存到所属视频项目，供后续查找和使用。它不同于另行保存一份文件副本。
_Avoid_: 下载（单独用来表达归档）

**另存副本**：
把已生成或获取的文件另外保存一份，供独立使用，不改变原有资料。
_Avoid_: 归档（用来表达另存副本）

**校对版本**：
人工修改已归档字幕的文字后另存的新字幕文件，命名为「标题-语言-校对」；原字幕保持不变，也不需要重新转写。只改文字，时间轴与未改动的条目保持原样。
_Avoid_: 覆盖原字幕、重新转写（用作校对）
